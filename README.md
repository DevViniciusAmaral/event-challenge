## ⚙️ Pré-requisitos

Antes de iniciar, certifique-se de ter instalado em sua máquina:

- [Node.js](https://nodejs.org/) (versão LTS recomendada, 18+)
- Gerenciador de pacotes `npm`, `yarn`, `pnpm` ou `bun`

---

## 🚀 Como Executar o Projeto

Siga os passos abaixo para preparar o ambiente e rodar a aplicação localmente:

### 1. Clonar o Repositório

Abra o seu terminal e execute:

```bash
git clone https://github.com/SEU_USUARIO/event-challenge.git
cd event-challenge
```

### 2. Instalar as Dependências

Instale todas as dependências necessárias executando:

```bash
npm install
```

### 3. Rodar em Ambiente de Desenvolvimento

Inicie o servidor de desenvolvimento local:

```bash
npm run dev
```

A aplicação estará disponível em [http://localhost:3000](http://localhost:3000).

## 🏗️ Outros Comandos Úteis

### Build de Produção

Para criar a build otimizada de produção da aplicação:

```bash
npm run build
```

### Visualizar Build de Produção

Para simular a aplicação buildada localmente:

```bash
npm run preview
```

### Linting e Formatação

Para verificar e formatar os arquivos de acordo com o padrão do projeto:

```bash
# Executar a verificação de formatação
npm run check

# Executar o linter
npm run lint

# Formatar e corrigir problemas automaticamente
npm run format
```
